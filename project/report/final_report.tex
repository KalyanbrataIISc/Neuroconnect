\begin{abstract}
This project investigates which canonical complex network model best approximates the topology of a real biological neural network. The empirical system studied is the \textit{Caenorhabditis elegans} connectome, represented as a graph derived from the OpenWorm ConnectomeToolbox dataset. Four synthetic graph families are generated and compared against the biological network: Erdos-Renyi random graphs, regular ring lattices, Watts-Strogatz small-world graphs, and Barabasi-Albert scale-free graphs. The comparison uses matched node counts, approximately matched edge counts or average degree, graph-theoretic metrics, robustness experiments, and a normalized multi-metric distance score. The results show that the Barabasi-Albert scale-free model gives the closest overall approximation under the chosen metric set, followed by the Watts-Strogatz small-world model. However, the biological graph is not well described by a single pure canonical model. The evidence supports a hybrid complex-network interpretation: the \textit{C. elegans} connectome combines hub structure, clustering, modularity, short paths, and non-random robustness behavior.
\end{abstract}

\chapter{Introduction}

Biological neural systems are complex networks. Their behavior emerges from many interacting cells, but the global properties of the system cannot be understood by examining isolated neurons alone. The topology of the connections among neurons affects information flow, robustness, modularity, and the balance between local specialization and global integration. Network science provides a practical framework for studying these properties using graph-theoretic models and metrics \cite{newman2010networks}.

This project asks a focused research question:

\begin{quote}
\textit{Which canonical network model best approximates the topology of a real biological neural network: random, lattice, small-world, or scale-free?}
\end{quote}

The empirical network analyzed here is the \textit{C. elegans} connectome, a widely used biological neural network dataset based on the nervous system reconstruction tradition originating with White et al. \cite{white1986structure}. The synthetic comparison models are selected because they represent central ideas in complex systems: random connectivity, local lattice structure, small-world shortcuts, and preferential-attachment hubs \cite{erdos1959random,watts1998collective,barabasi1999emergence}.

The goal is not to claim that a nervous system is exactly one simple mathematical model. Biological networks are shaped by development, spatial embedding, functional constraints, and evolutionary pressures. Instead, the goal is to build a reproducible end-to-end analysis, quantify similarity across interpretable metrics, and make a cautious scientific conclusion about which canonical model is the closest approximation.

\chapter{Background}

\section{Complex Systems and Network Topology}

A complex system consists of many interacting components whose collective behavior can display emergent structure. In neural systems, individual neurons and muscles interact through synaptic and electrical connections. When these interactions are represented as a graph, nodes correspond to biological units and edges correspond to connections. Graph topology then becomes a compact way to study system-level organization.

Important network properties include clustering, path length, hubs, modularity, assortativity, and robustness. Clustering measures the tendency of neighboring nodes to be connected. Path length measures how many steps separate nodes on average. Hubs are unusually high-degree nodes that can support integration but also create vulnerability to targeted damage. Modularity measures the extent to which nodes form communities or modules. Robustness experiments test how network connectivity changes when nodes are removed.

\section{Random Networks}

The Erdos-Renyi random graph is a baseline model in which edges are placed randomly \cite{erdos1959random}. In this project, the random model is generated as $G(n,m)$ so that it matches the empirical graph's number of nodes and edges. Random graphs often have short path lengths, especially when the graph is sufficiently dense, but they usually have low clustering and weak hub structure compared with many biological networks.

\section{Lattice Networks}

A regular lattice graph represents local connectivity. In a ring lattice, each node connects to a fixed number of nearest neighbors. Such graphs tend to have high clustering but long path lengths because information must travel through many local steps to cross the network. A lattice model is useful as a structured opposite to a random graph.

\section{Small-World Networks}

Watts and Strogatz showed that networks can combine high clustering with short path lengths when a small number of local lattice edges are rewired as long-range shortcuts \cite{watts1998collective}. This is important for biological systems because nervous systems often require both local processing and efficient communication across distant functional groups. Small-world structure has therefore become a common hypothesis in neural and biological network analysis.

\section{Scale-Free Networks}

The Barabasi-Albert model generates networks through growth and preferential attachment \cite{barabasi1999emergence}. New nodes attach preferentially to already well-connected nodes, producing hubs and a heterogeneous degree distribution. Scale-free-like organization can support efficient integration and robustness to random failure, but it also makes networks vulnerable to targeted removal of hubs.

\section{Biological Neural Networks as Hybrid Systems}

Real neural systems rarely match one canonical model exactly. Biological connectomes can show small-world organization, modularity, hubs, and robustness patterns simultaneously. A cautious analysis should therefore compare models quantitatively while avoiding the claim that one simple model fully explains a biological nervous system.

\chapter{Methods}

\section{Project Pipeline}

The analysis pipeline performs the following steps:

\begin{enumerate}
    \item Download the \textit{C. elegans} connectome into the raw data directory.
    \item Load the raw edge table into Python.
    \item Build directed weighted and undirected projected NetworkX graphs.
    \item Remove self-loops.
    \item Save the processed edge list.
    \item Generate matched synthetic graph models.
    \item Compute graph metrics for the empirical and synthetic graphs.
    \item Run robustness experiments under random and targeted node removal.
    \item Compare synthetic models using normalized metric distance.
    \item Save all tables, figures, and report-ready outputs.
\end{enumerate}

The implementation uses Python with pandas for tabular data handling, NetworkX for graph construction and metrics, and Matplotlib for visualization \cite{mckinney2010pandas,hagberg2008networkx,hunter2007matplotlib}.

The reproducible command is:

\begin{verbatim}
conda run -n coglab python src/main.py
\end{verbatim}

\section{Synthetic Network Generation}

Let $G_{\mathrm{real}}$ denote the undirected \textit{C. elegans} graph, with $N=309$ nodes and $M=2511$ edges. The empirical average degree is

\begin{equation}
\bar{k} = \frac{2M}{N} = 16.25.
\end{equation}

Four synthetic models are generated:

\begin{itemize}
    \item \textbf{Erdos-Renyi random graph:} generated as $G(n,m)$ with $n=309$ and $m=2511$, matching the empirical node and edge counts exactly.
    \item \textbf{Regular lattice graph:} generated as a ring lattice with approximately the empirical average degree.
    \item \textbf{Watts-Strogatz small-world graph:} generated with the same node count and approximate average degree. The ten rewiring probabilities are listed in Table~\ref{tab:ws-sweep}.
    \item \textbf{Barabasi-Albert scale-free graph:} generated with an attachment parameter chosen to approximate the empirical average degree.
\end{itemize}

\section{Graph Metrics}

For each graph, the following metrics are computed:

\begin{itemize}
    \item Number of nodes and edges
    \item Density
    \item Average degree and degree variance
    \item Average clustering coefficient
    \item Transitivity
    \item Average shortest path length on the largest connected component
    \item Diameter on the largest connected component
    \item Global efficiency \cite{latora2001efficient}
    \item Maximum degree and top hub nodes
    \item Degree, betweenness, and closeness centrality
    \item Greedy modularity communities and modularity \cite{girvan2002community}
    \item Degree assortativity
\end{itemize}

\section{Model Distance}

The final quantitative comparison uses a normalized metric distance. For model $s$ and empirical graph $r$, the distance is

\begin{equation}
D(s,r) =
\frac{1}{|Q|}
\sum_{q \in Q}
\frac{|x_{s,q}-x_{r,q}|}{|x_{r,q}|},
\end{equation}

where $Q$ is the selected metric set. The selected metrics are average clustering coefficient, average shortest path length, density, degree variance, modularity, assortativity, and global efficiency. A lower value indicates a closer match to the empirical graph under this chosen metric objective.

\section{Robustness Experiments}

Two node-removal experiments are performed:

\begin{itemize}
    \item \textbf{Random removal:} remove 0\%, 5\%, 10\%, 20\%, 30\%, 40\%, and 50\% of nodes uniformly at random. Each fraction is repeated 20 times, and the mean and standard deviation of the largest connected component fraction are recorded.
    \item \textbf{Targeted removal:} remove nodes in descending order of degree and record the largest connected component fraction after each removal fraction.
\end{itemize}

\chapter{Discussion}

The final ranking indicates that the Barabasi-Albert scale-free model is the closest approximation to the \textit{C. elegans} graph under the selected normalized metric distance. The main reason is degree heterogeneity. The empirical graph contains clear hubs, and its degree variance is much larger than the Erdos-Renyi, lattice, and Watts-Strogatz graphs generated here.

However, the scale-free interpretation is incomplete. The biological graph also has substantial clustering, modularity, and short path length. These are small-world and modular-network properties. The Watts-Strogatz model captures some of this behavior, especially short path length and clustering tradeoffs, and it ranks second in the final comparison.

The Erdos-Renyi graph is useful as a density-matched random baseline, but it underestimates clustering and hub structure. The regular lattice graph captures strong local clustering but has path lengths that are too long and no realistic degree heterogeneity. Together, these comparisons show why the empirical nervous system should be interpreted as a hybrid complex network rather than a pure example of any single canonical model.

From a complex systems perspective, this is the most meaningful result. Biological neural organization emerges from interactions among many constrained components. The resulting topology combines integration, segregation, local specialization, hub-mediated communication, modular structure, and robustness tradeoffs.

\chapter{Limitations}

This analysis is based on one biological connectome dataset. It does not prove that the human brain, all animal brains, or all biological neural networks follow the same topology. Network properties depend on species, scale, developmental stage, measurement method, and preprocessing.

The core analysis uses an undirected unweighted projection. This makes the canonical model comparison straightforward, but it discards directionality, synaptic strength, and the distinction between chemical and electrical connections. Directed and weighted analyses could change some metric values and interpretations.

The model ranking depends on metric selection and normalization. If clustering were weighted more heavily, Watts-Strogatz could become more favorable. If degree heterogeneity were emphasized more strongly, Barabasi-Albert would become even more favorable. The synthetic graphs are also stochastic, so a more extensive study should average over many generated graphs per model and report uncertainty in the ranking.

Finally, canonical graph models are simplified baselines. Real connectomes are shaped by spatial constraints, body layout, functional circuits, cell types, development, and evolution. Those mechanisms are not explicitly represented in the four models tested here.

\chapter{Conclusion}

The research question asked which canonical model best approximates a real biological neural network: random, lattice, small-world, or scale-free. For the OpenWorm \textit{C. elegans} connectome dataset and the selected metric-distance objective, the Barabasi-Albert scale-free model is the closest approximation. The Watts-Strogatz small-world model ranks second, followed by Erdos-Renyi random and regular lattice models.

The strongest scientific conclusion is not that the \textit{C. elegans} connectome is purely scale-free. Instead, it is better described as a hybrid biological complex network. It has hubs and degree heterogeneity, short path lengths, nontrivial clustering, modular organization, and stronger vulnerability to targeted hub removal than to random node removal. These features are consistent with biological systems in which topology reflects both efficient communication and robustness tradeoffs.

\chapter{Future Work}

Future versions of this project could extend the analysis in several directions:

\begin{itemize}
    \item Compare directed and weighted versions of the connectome.
    \item Separate chemical and electrical subnetworks.
    \item Average synthetic metrics across many random seeds.
    \item Add motif analysis and rich-club analysis.
    \item Compare additional connectome datasets from other organisms or modalities.
    \item Test spatial, modular, or biologically constrained generative network models.
\end{itemize}
